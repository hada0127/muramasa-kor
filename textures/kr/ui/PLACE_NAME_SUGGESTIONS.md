## 축약 전략

### 패턴 1: 물결표(~) & 가운뎃점(·) 활용
```
도카이도 후지카와 아카사카 사이 가도
→ 도카이도: 후지카와·아카사카  (지역명 + 지점 간단히)
→ 후지카와~아카사카 가도  (지점만 강조)
```

### 패턴 2: 불필요한 설명 삭제
```
곤고산 산정 다카마가하라 입구
→ 곤고산 다카마가하라  ('입구' 삭제 — 장소명만으로 충분)
```

### 패턴 3: 지역명 생략
```
에도 다이콘 번저 시모야시키
→ 다이콘 번저 시모야시키  ('에도' 생략 가능)
```

### 패턴 4: 성씨/직위 생략
```
이누가미 도쿠가와 쓰나요시
→ 이누가미 츠나요시  (성씨 '도쿠가와' 생략)
→ 쇼군 츠나요시  (직위로 대체)
```

## map_notes.json 확장

각 지명에 다음 필드 추가:
```json
{
  "original": "원본 일본어",
  "korean": "현재 번역",
  "short_alternative": "짧은 대안 (6-10자)",
  "medium_alternative": "중간 대안 (10-14자)",
  "reason": "변경 이유",
  "suggested": true
}
```

## 사용자 선택 옵션

**map_notes.json에 3가지 버전이 저장되므로, UI 레이아웃에 맞춰 선택 가능:**

1. **현재 번역 (`korean`)** — 가장 자세한 정보 (13-20자)
2. **중간 대안 (`medium_alternative`)** — 균형잡힌 길이 (10-14자, 권장)
3. **짧은 대안 (`short_alternative`)** — 가장 간결함 (6-11자)
