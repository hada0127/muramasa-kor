### ★ 핵심 발견 (2026-05-25, 데이터로 확정) — 게임은 폰트 페이지가 여러 장이다

기존 PoC(`docs/03-analysis/jongseong-expansion-poc.md`)는 **한 페이지(font01, 河)를
세로로 늘리는** 시도만 했고 전부 실패했다. 그러나 실제 게임 폰트 구조를 뜯어보니:

- 폰트 컨테이너 FTX = **16개 정적 GXT 페이지** (각 1024×1024, 32px 그리드 = 1024 cell)
  - `font.ftx`(8.4MB) = 8장: `font00~03` + 굵기변형 `font00b~03b`
  - `font2a.ftx`(4.2MB) = 4장 (손글씨체 A), `font2b.ftx`(4.2MB) = 4장 (손글씨체 B)
- **SJIS 한자 페이지는 3개** (각 폰트 스타일별로 존재):
  | 페이지 | 파일(활자체) | cell 0 글자 | SJIS 범위 | 게임 사용 한자 | 빈 셀 |
  |---|---|---|---|---|---|
  | Page0 | font01 | 河 | 0x89CD~0x8F63 | 638 | 386 (※우리가 한글화한 유일 페이지) |
  | Page1 | font02 | 重 | 0x8F64~0x94B8 | 620 | **404** |
  | Page2 | font03 | 隼 | 0x94B9~0x9A4F | 434 | **590** |
- 우리는 **Page0(河)만** 스타일별(6706A53E 활자 / A8E6FDD1·8665CE08·18747565 손글씨)로
  한글 오버레이했다. **Page1(重)·Page2(隼)는 손도 안 댔다.**
- 빈 셀 합계 **994개**(Page1 404 + Page2 590) → 미커버 1,390자 대부분을 직접 글리프로 매핑 가능.
- (분석 스크립트/추출물: `temp/font_pages/`, 페이지 미리보기 `temp/preview/font_p*.png`)

#### 방법 B — eboot.bin ARM 패치로 atlas/UV 1024→2048 확장 (차선책)
- **원리**: eboot.elf(복호화 완료)의 폰트 cell→UV 변환 루틴에서 1024 hardcoded
  (float 0x44800000 또는 비트시프트/마스크)를 찾아 2048로 패치 → 한 페이지 32×64=2048 슬롯.
- **실현 가능성**: 보통. Ghidra/Capstone ARMv7 리버싱 필요.
- **난이도/공수**: 매우 높음.
- **리스크**: 높음. 1024 상수가 폰트 외 UI/배경 공용 수학에 쓰이면 전체 그래픽 깨짐.
- **첫 단계**: Ghidra에 eboot.elf 로드 → "other/font.ftx" 문자열 VMA 0x81304AE0 XREF 추적 →
  폰트 구조체 초기화/샘플 함수에서 0x44800000(1024.0f)·0x400(1024) movw/movt/vldr 탐색.
- **비고**: 방법 A로 충분하면 불필요. A가 페이지 부족(2,350 미달)일 때만.

#### 방법 C — 16px 서브셀 packing (한 cell을 4분할, 4096자) (보류)
- **원리**: 32×32 cell을 16×16 4개로 쪼개 한 페이지에 4배 packing.
- **실현 가능성**: 낮음. UV offset + AdvanceWidth + 줄간격까지 전부 동적 패치 필요(eboot).
- **리스크**: 매우 높음. Vita 네이티브 960×544에서 16px 받침 글자 가독성 불가에 가까움.
- **결론**: 방법 A/B 대비 이점 없음 → 보류.

#### 방법 D — 초·중·종성 조합형(0폭 렌더링) (창의적, 보류)
- **원리**: 한글을 자모 분리해 NMS에 입력, 자모 폭을 0으로 만들어 겹쳐 렌더 → 글리프
  ~200개로 전체 음절 표현. gemini 제안.
- **실현 가능성**: 중간. 게임 텍스트 엔진의 문자폭(advance) 테이블 존재·조정 가능해야 함.
- **난이도/공수**: 높음. NMS 컴파일러에 오토마타 로직 신설, 자모 위치 정합 필요.
- **리스크**: 줄바꿈 글자수 오해로 UI 박스 넘침, 알파 겹침 문제.
- **첫 단계**: font.ftx/게임 데이터에서 문자폭 테이블 탐색 → 임의 글자 폭 0 설정 시 겹쳐
  출력되는지 확인.
- **결론**: 방법 A가 슬롯을 충분히 주면 불필요. A 실패 시 검토.
