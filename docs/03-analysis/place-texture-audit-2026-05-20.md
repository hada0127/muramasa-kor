# Place Texture Audit 2026-05-20

지명 텍스처의 원본 한자, 현재 한글 매핑, 시스템 메시지/대사/고유명사 근거를 대조한 작업 기록이다. `wii/` 참고 폴더는 현재 작업트리에 없어 Vita 메시지와 기존 scene intro 자료를 기준으로 삼았다.

## 판정 기준
- `sysmsg`/`sysmsg_main`의 장소 소개 문구가 있으면 해당 번역을 우선한다.
- 대사와 고유명사 표기가 있으면 그 표기를 우선한다.
- 원본에 흰 글자가 없는 붓자국은 장식으로 보고 한글을 렌더링하지 않는다.
