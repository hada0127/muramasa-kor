# 실기(real PS Vita) 한글 패치 — 쉬운 설치 가이드 [베타]

> 이 문서는 **실제 PS Vita 본체**에 한글 패치를 까는 가장 쉬운 방법을 처음부터 끝까지 따라가는
> 초보자용 안내다. 에뮬레이터(Vita3K) 사용자는 이 문서가 필요 없다 — [README의 GUI 설치](../README.md#️-가장-쉬운-설치--통합-gui-도구-권장)만 보면 된다.

실기 패치는 한글 텍스처/폰트를 게임 데이터(CPK) 안에 직접 구워 넣는 방식이라, 저작권상 완성본을
배포할 수 없다. **본인 Vita에 있는 원본 게임 파일로 패치를 직접 만든다.** 아래 도구가 그 과정을
거의 자동으로 처리한다.

> **🚀 3줄 요약 (이미 익숙한 사람용)**
> 1. PC의 **Vita3K에 게임을 설치**(본편+1.06+DLC). ← 패치 재료인 *복호화* CPK가 여기 생긴다
> 2. 패치 도구 실행 → "실기 PS Vita" 선택 → **Vita3K 폴더만 지정** → **[패치 시작]**
> 3. 생긴 `ux0` 폴더를 Vita의 `ux0:/`에 복사 → 재부팅 (rePatch 켜져 있어야 함)
>
> 처음이라면 아래 5단계를 그대로 따라 하면 된다.

> ⚠️ **왜 Vita3K가 필요한가** — 실기 본체의 게임 파일은 *암호화*돼 있어 그대로는 패치 못 한다.
> 복호화된 원본 CPK는 PC의 Vita3K가 게임 설치 시 풀어 둔 것을 쓴다(또는 MaiDumpTool로 뽑은 복호화 덤프).
> 도구는 그 Vita3K 폴더만 가리키면 본편·DLC CPK를 알아서 찾는다.

전체 흐름은 5단계다.

```
[1] rePatch 플러그인 설치  →  [2] Vita3K에 게임 설치(복호화 CPK)  →  [3] GUI로 패치 만들기
        →  [4] 결과를 Vita에 복사  →  [5] (✕ 버튼 쓸 때만) Vita 설정
```

---

## 준비물

- **개조(HENkaku/h-encore 등)된 PS Vita** — 정품 게임 `Muramasa Rebirth`(US판) + 1.06 업데이트가 설치돼 있어야 한다. DLC는 선택.
- **VitaShell** — Vita와 PC 사이에 파일을 주고받는 앱.
- **PC** — Windows(가장 쉬움) 또는 macOS/Linux.
- **USB 케이블** — Vita를 PC에 연결.

---

## 1단계 — rePatch 플러그인 설치

rePatch는 "게임 데이터를 통째로 다른 파일로 바꿔치기"해주는 플러그인이다. 한글 CPK를 게임에 적용하려면 반드시 필요하다.

가장 쉬운 설치법은 **AutoPlugin2**를 쓰는 것이다.

1. Vita에 AutoPlugin2가 없으면 먼저 설치한다(검색: `AutoPlugin2 vpk`).
2. AutoPlugin2를 실행하고 목록에서 **rePatch**를 찾아 설치를 진행한다.
3. 설치 후 안내에 따라 **Vita를 재부팅**한다.

> 수동 설치를 선호하면 rePatch의 `rePatch.skprx`를 `ux0:/tai/` 에 넣고 `ux0:/tai/config.txt` 의
> `*KERNEL` 섹션에 경로를 추가한 뒤 재부팅한다. (자세한 건 rePatch 공식 안내를 참고)

rePatch가 켜져 있는지 모르겠다면, 일단 끝까지 진행한 뒤 게임에서 한글이 안 나오면 이 단계를 다시 점검하면 된다.

---

## 2단계 — PC의 Vita3K에 게임 설치 (복호화 CPK 확보)

한글 패치는 **복호화된** 원본 CPK로 만든다. 그 복호화본은 PC의 **Vita3K 에뮬레이터에 게임을
설치**하면 `ux0/app/PCSE00240/`(+DLC는 `ux0/addcont/...`)에 자동으로 풀린다.

1. PC에 **Vita3K**를 설치하고 실행한다.
2. 본인이 가진 무라마사 게임을 **Vita3K에 설치**한다(본편 + 1.06 업데이트 + (선택)DLC).
   - 보통 `.vpk`/`.pkg`(+zRIF) 또는 MaiDumpTool 백업으로 설치한다. (설치 방법은 Vita3K 위키 참고)
3. 한 번 게임이 목록에 떠서 정상 실행되면 준비 끝 — Vita3K가 복호화 CPK를 만들어 둔 상태다.

> ⚠️ 실기 본체에서 VitaShell로 꺼낸 `app/PCSE00240/*.cpk` 는 **암호화**돼 있어 패치 재료로 못 쓴다.
> 반드시 위처럼 **Vita3K가 풀어 둔** CPK(또는 MaiDumpTool **복호화** 덤프)를 사용해야 한다.

---

## 3단계 — GUI 도구로 패치 만들기

1. 릴리즈에서 `muramasa-kor-vX-patcher-windows.zip` 을 받아 압축을 푼다.
   - **Windows**: 같은 릴리즈의 `MuramasaPatcher.exe` 를 받아 그 폴더 안에 넣고 더블클릭한다.
     파란 SmartScreen 경고가 뜨면 **"추가 정보" → "실행"**.
   - **macOS/Linux**: 폴더 안의 `실행_Mac.command`(맥) 또는 `실행_Linux.sh`(리눅스)를 실행한다(파이썬 3.9+ 필요).
2. 창 맨 위 **"① 원본 위치 — Vita3K 설치 폴더"** 가 자동으로 채워졌는지 확인한다(비었으면 [찾아보기]로 지정).
3. **"② 설치 대상"** 에서 **"실기 PS Vita (rePatch)"** 를 고른다.
   - 본편·DLC CPK는 위 Vita3K 폴더에서 **자동으로 읽는다**(따로 파일을 고를 필요 없음).
   - **결과 저장 폴더**: 비워 두면 바탕화면 `MuramasaPatchOut` 에 만들어진다.
4. **결정 버튼 표시**는 기본 **○**으로 둔다(✕를 원하면 5단계도 함께).
5. **[패치 시작]** 을 누른다. PC 성능에 따라 1~5분 걸린다. "완료" 창이 뜨면 성공이다.

결과 저장 폴더 안에 `ux0` 폴더가 만들어진다.

---

## 4단계 — 결과를 Vita에 복사

1. Vita를 다시 PC에 연결한다(VitaShell USB 모드).
2. 3단계에서 만들어진 **`ux0` 폴더의 내용**을 Vita의 **`ux0:/`** 아래에 그대로 복사(덮어쓰기)한다.
   복사가 끝나면 Vita에 다음 파일들이 생긴다.
   ```
   ux0:/rePatch/PCSE00240/NinPri.cpk
   ux0:/rePatch/PCSE00240/NinPriPatch.cpk
   (DLC가 있으면) ux0:/reAddcont/PCSE00240/OBOROMURAMASAPK1~4/NinPriPack1~4.cpk
   ```
3. Vita를 **재부팅**하고 게임을 실행한다. 한글이 나오면 성공이다. 🎉

---

## 5단계 — (✕ 버튼을 골랐을 때만) Vita 설정

GUI에서 결정 버튼을 **✕** 로 골랐다면, 화면 표시뿐 아니라 실제 입력도 ✕가 "확인"이 되도록 Vita 본체 설정을 맞춰야 한다.

- Vita **설정 → 시스템 → (엔터 버튼 / 결정 버튼 할당)** 에서 **✕(Cross)** 로 변경.

기본 ○ 를 골랐다면 이 단계는 건너뛴다.

## 문제 해결

| 증상 | 확인할 것 |
|---|---|
| 게임에서 한글이 전혀 안 나옴 | rePatch가 켜져 있는지(1단계), `ux0:/rePatch/PCSE00240/` 에 cpk가 들어갔는지(4단계) 재확인 후 재부팅 |
| "패치 시작"에서 오류 / "원본을 찾지 못함" | ① 지정한 게 Vita3K 설치 폴더가 맞는지, ② Vita3K에 게임(1.06 포함)이 설치돼 있는지 확인 |
| 일부 화면만 영문/한자 | DLC 화면이면 그 DLC가 **Vita3K에 설치**돼 있는지 확인(설치돼 있으면 자동 패치됨) |
| ✕가 취소로 동작 | 5단계의 Vita 결정 버튼 설정 확인 |
| Windows에서 exe가 안 켜짐 | SmartScreen "추가 정보 → 실행". 백신이 막으면 예외 추가 |
| macOS에서 "확인되지 않은 개발자" | Finder 우클릭 → 열기, 또는 터미널 `xattr -dr com.apple.quarantine "실행_Mac.command"` |

> **실기 표시는 아직 베타다.** 한글이 깨지거나 부팅이 안 되는 등 문제가 있으면 어떤 화면에서
> 그런지와 함께 제보해 주면 큰 도움이 된다.
