# Muramasa Rebirth 한글 패치 v1.4.3

사람마다 Vita3K 설치 위치가 조금씩 달라서, 자동 패처가 CPK는 패치했는데 한글 텍스처가 적용되지 않던
문제(이슈 #19)를 해결했습니다.

## 이슈 #19 — CPK는 패치됐는데 한글이 안 나오던 문제

- **증상**: 자동 패처가 CPK는 Roaming(`%APPDATA%\Vita3K\Vita3K`) 폴더에 정상 패치했지만, 한글
  텍스처가 적용되지 않아 게임에 한글이 표시되지 않았습니다. 사용자가 직접 Vita3K.exe 가 있는 폴더에
  `textures/import/PCSE00240` 를 만들어 복사하면 그제서야 한글이 나왔습니다.
- **원인**: Vita3K 는 게임 파일(`ux0`/CPK)을 읽는 폴더와 교체 텍스처(`textures/import`)를 읽는 폴더가
  **서로 다를 수 있습니다.** 특히 Windows 일반 빌드는 텍스처를 **Vita3K.exe 가 있는 폴더**에서 읽는데,
  게임 파일은 Roaming 폴더에 둡니다. 기존 패처는 텍스처를 게임 파일 폴더 기준으로만 복사해서, 이 두
  폴더가 다른 사용자에게는 텍스처가 엉뚱한 곳에 들어갔습니다.

## 이번 버전에서 달라진 점

- Vita3K `config.yml`(`pref-path`/`vita_fs_path`)을 읽어 실제 게임 폴더를 정확히 찾습니다. 데이터 폴더를
  옮긴 사용자도 정상 인식합니다.
- 한글 텍스처를 **알아낼 수 있는 모든 Vita3K 폴더 후보에 함께 설치**합니다(게임 폴더, 그 상위/`fs`,
  `config.yml` 폴더, 사용자가 지정한 Vita3K.exe 폴더, 실행 중인 Vita3K 프로세스 폴더, 흔한 설치 위치).
  실제 Vita3K 폴더처럼 보이는 곳에만 넣어 엉뚱한 폴더는 건드리지 않습니다.
- 설치 도구(GUI)에 안내를 추가했습니다 — 한글이 일부만 적용되면 **Vita3K.exe 가 있는 폴더를 직접 지정**한
  뒤 다시 실행하면 됩니다. Windows 자동 모드에서 exe 폴더를 못 찾으면 그 안내를 화면에 띄웁니다.

## 참고

- 이번 변경은 **설치 도구(패처)만** 고친 것으로, 번역·폰트·CPK 내용은 v1.4.2 와 동일합니다.
- 이미 v1.4.2 로 잘 설치된 분은 다시 받을 필요는 없습니다. 한글 텍스처가 일부/전부 안 보이던 분만
  v1.4.3 으로 다시 설치하거나, Vita3K.exe 폴더를 지정해 재실행하세요.
