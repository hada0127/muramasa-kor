# 무라마사 리버스 한글패치 v1.1.0

**아이템 이름 표기 통일**과 **타이틀 화면 화질 개선**을 담은 업데이트입니다.

## 🔧 이번에 고친 점

**1. 아이템 이름이 화면마다 다르게 보이던 문제**
메뉴의 아이템 이름·설명과, 그림으로 그려진 도감/효과 화면의 이름이 서로 달랐어요. 이를 **일본어 원작 기준으로 전부 통일**했습니다.
- **곡옥(장신구) 이름이 서로 뒤섞여 있던 것**을 바로잡았습니다. 영어판을 번역할 때 색·종류가 잘못 맞춰졌던 것을 원작 효과에 맞게 정리: **호박 곡옥 · 황천 곡옥 · 마노 곡옥 · 제사 곡옥 · 영혼 곡옥**
- 이름이 뒤바뀌거나 엉뚱했던 것 수정: White Lightning(술)→**탁주**, Divine Panacea→**영방반혼단**, 체력 강화→**지구 강화** 등
- 어색한 표기 정리: 닌자발→**닌자술**, 곡옥류 띄어쓰기 통일

**2. 타이틀 화면이 흐릿하던 문제**
오보로 무라마사 / 겐로쿠 괴기담 로고와 뒤의 한문 배경 그림이 저화질로 보였어요. 초반에 고화질(HD) 텍스처가 아닌 그림 위에 한글을 입혔던 게 남아 있던 탓입니다. **HD 텍스처를 기준으로 다시 작업해 선명하게** 만들었습니다.
- 타이틀 로고(오보로 무라마사)와 배경 한문(元禄怪奇譚·朧村正)을 고화질로 교체
- 한글 부제는 원작 느낌의 부드러운 글로우로 다시 입힘

**3. 지명 표기 다듬기**
지도 지명 **'도토미'** 표기를 정리했습니다.

## 설치 방법
이전 버전과 동일합니다. 동봉된 패처(Windows/macOS/Linux)를 실행하면 원본 CPK에 패치가 적용되고, 폰트·텍스처 파일이 Vita3K에 설치됩니다. 자세한 방법은 패처 안내와 README를 참고하세요.
