# 무라마사 리버스 한글패치 v1.0.3

대사 글자 깨짐 1가지와 **필살기(오의) 이름 표기**를 원작 기준으로 싹 정리한 패치입니다.

## 🔧 이번에 고친 점

**1. 대사에서 일부 글자가 `[` `]` 로 깨지던 문제**
"물어뜯어"가 "물어`[`어", "손님이 뜸해서"가 "손님이 `]`해서"처럼 **'뜯'·'뜸' 두 글자가 대괄호로 잘못** 보였어요. 글자가 들어가는 칸이 특수문자 칸과 겹쳐서 생긴 문제로, 칸을 옮겨 **제 글자로 또렷하게** 나오도록 고쳤습니다.

**2. 필살기(오의) 이름이 화면마다 다르게 보이던 문제**
무기 설명창의 오의 이름과 기술 도감 화면의 이름이 서로 달랐어요. (예: 같은 기술이 한쪽은 "팔정 베기", 다른 쪽은 "채썰기") 이를 **일본어 원작 이름 기준으로 전부 통일**했습니다.
- 영어판을 거치며 뜻이 바뀐 이름들을 원작에 맞게 정리: 별똥별→**성천 혜성**, 채썰기→**팔정 베기**, 십자베기→**그림자 십문자**, 나선은하→**성천 풍차**, 천지베기→**천지 일섬** 등
- 헷갈리던 이름 정리: 妖炎 "요염"→**요괴불꽃**, 雷光 계열→**뇌광**, 鬼火嵐→**도깨비불 폭풍**
- 번호 표기 통일: 단계는 `이름 2`, 연타 기술은 `이름 3연` 식으로 (예: **요괴벼락 3연**, **화염 4연**)

**3. 글씨 크기·문구 다듬기**
길어진 오의 이름이 칸에 잘 들어가도록 **글씨 크기를 맞췄고**, 오프닝 나레이션 문구도 자연스럽게 다듬었습니다.

## 설치 방법
이전 버전과 동일합니다. 동봉된 패처(Windows/macOS/Linux)를 실행하면 원본 CPK에 패치가 적용되고, 폰트·텍스처 파일이 Vita3K에 설치됩니다. 자세한 방법은 패처 안내와 README를 참고하세요.
