# 무라마사 리버스 한글패치 v1.2.0

선택/확인 버튼을 **○ 대신 ✕로** 보고 싶은 분을 위한 **✕ 버튼 추가팩**이 새로 생겼습니다. (이슈 #12)

## 🆕 ✕ 버튼 추가팩 (선택 사항)

기본 패치는 지금처럼 **○(동그라미)** 를 그대로 씁니다. ✕를 선호하는 분만 추가팩을 덮어쓰면 버튼 표시가 ✕로 바뀝니다.

바뀌는 곳:
- 메뉴 아래쪽 **선택/확인 아이콘** ○ → ✕ (확인=✕, 취소=○)
- 타이틀 **시작 화면**의 "◯ 누르세요" 버튼 모양 ○ → ✕

### ⚠️ Vita3K 설정도 함께 바꿔야 합니다
게임이 버튼 모양을 직접 그리기 때문에, 이 팩은 **화면에 보이는 모양만** ✕로 바꿉니다.
**실제로 ✕가 "확인"이 되게 하려면** Vita3K 설정에서 아래도 함께 바꿔주세요:

> Vita3K → Settings → (System/Controls) → **Enter Button Assignment = Cross**

- 지금 ○로 잘 쓰고 계신 분은 이 팩이 **필요 없습니다.**

### 설치 / 되돌리기
1. 먼저 기본 한글 패치를 설치합니다.
2. `muramasa-kor-xbutton-v1.2.0.zip`을 풀고 `apply_xbutton_windows.bat`(Windows) / `apply_xbutton_macos.command`(macOS) / `python3 apply_xbutton.py`(Linux)를 실행합니다.
3. ○로 되돌리려면 `python3 apply_xbutton.py --restore`.
