# Muramasa Rebirth 한글 패치 v1.4.1

v1.4.0 통합 GUI 설치 도구의 코드 리뷰(codex + agy)에서 발견된 문제들을 수정했습니다.

## 수정

- **Vita3K 모드에서 ✕ 버튼 선택이 무시되던 문제** — 이제 Vita3K에서도 ✕를 고르면 ✕ 버튼 텍스처가
  함께 설치됩니다(설정에서 Enter Button = Cross 병행 필요).
- **"원본으로 복원"이 한글 import 텍스처를 남기던 문제** — 복원 시 우리가 설치한 import 텍스처도 함께
  제거합니다(HD 텍스처 팩 사용자는 팩 재설치 필요).
- **Windows exe에서 드물게 창이 조용히 닫히던 문제** — 콘솔 없는 빌드(`console=False`)에서 표준 출력이
  비어 있을 때 발생할 수 있던 크래시를 방지했습니다.

## 안정성·편의 개선

- 패치 진행 중 창을 닫으면 경고를 띄워 중단 사고를 방지.
- 잘못된 DLC 경로는 패치 시작 전에 즉시 알려줌(긴 작업 후 실패 방지).
- 시작 시 드라이브 자동 탐지가 멈춘 것처럼 보이지 않도록 창을 먼저 띄운 뒤 탐지.
- 실기 패치 완료 안내에 "ux0 폴더를 Vita에 복사" 문구를 구체화.
- exe 빌드 시 패치 엔진이 간접 사용하는 모듈을 명시해 누락 위험 제거.

## 참고

패치 내용 자체(번역·텍스처)는 v1.4.0과 동일합니다. 설치 도구 안정화 릴리스입니다.
원본 게임 데이터는 포함하지 않습니다 — 본인 원본 CPK로 패치를 직접 만듭니다.
