# ✕ 버튼 추가팩 (이슈 #12)

선택/확인 버튼이 **○(동그라미)** 로 보여 헷갈리는 분들을 위해, 그 표시를 **✕(엑스)** 로 바꾸는 추가팩입니다.
기본 한글 패치는 그대로 ○를 쓰고, 이 팩은 **원하는 분만 추가로 덮어쓰면** 됩니다.

## ⚠️ 먼저 읽어주세요 — Vita3K 설정도 함께 바꿔야 합니다

게임이 버튼 모양을 직접 그리기 때문에, 이 팩은 **화면에 보이는 모양만** ✕로 바꿉니다.
**실제로 ✕ 버튼이 "확인"이 되게 하려면** Vita3K 설정도 함께 바꿔야 합니다:

> Vita3K → Settings → (System/Controls) → **Enter Button Assignment = Cross**

- 지금 ○로 잘 쓰고 계신 분은 이 팩이 **필요 없습니다.**
- ✕로 확인하는 데 익숙한 분만, 위 설정(Cross) + 이 팩을 함께 쓰면 화면 표시와 버튼이 일치합니다.

## 무엇이 바뀌나요
- 메뉴 아래쪽 **선택/확인 아이콘** ○ → ✕ (확인=✕, 취소=○)
- 타이틀 **시작 화면**의 "◯ 누르세요" 버튼 모양 ○ → ✕

## 설치
1. 먼저 **기본 한글 패치**가 설치돼 있어야 합니다.
2. 이 팩(zip)을 풀고:
   - **Windows**: `apply_xbutton_windows.bat` 실행
   - **macOS**: `apply_xbutton_macos.command` 실행
   - **Linux**: `python3 apply_xbutton.py`
3. Vita3K를 재시작하면 버튼이 ✕로 보입니다.

## ○ 버튼으로 되돌리기
```
python3 apply_xbutton.py --restore
```

## 안드로이드 등 수동 설치
- `xbutton/` 폴더의 PNG를 Vita3K의 `textures/import/PCSE00240/` 에 덮어쓰면 됩니다.
- 되돌리려면 `restore-o/` 폴더의 PNG를 같은 곳에 덮어쓰세요.
