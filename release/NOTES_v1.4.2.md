# Muramasa Rebirth 한글 패치 v1.4.2

실기(real PS Vita) 설치 흐름을 정비하고, 제보된 두 가지 표시 문제(이슈 #17·#18)를 해결했습니다.

## 실기 설치 UX 개편 (입력 = Vita3K 폴더)

- 패치는 **복호화된** 원본 CPK로 만드는데, 실기 본체의 게임 파일은 *암호화*돼 있어 그대로 쓸 수 없습니다.
  복호화본은 PC의 **Vita3K가 게임 설치 시 풀어 둔 것**이 유일하게 믿을 수 있는 출처입니다.
- 그래서 설치 도구의 입력을 **"Vita3K 설치 폴더" 하나로 통일**했습니다. CPK 파일을 일일이 찾아 지정할
  필요 없이, Vita3K 폴더만 가리키면 본편·DLC CPK를 자동으로 읽습니다.
  - **에뮬레이터**: 그 Vita3K에 바로 설치(기존 방식, HD 텍스처팩 화질 보존).
  - **실기**: 복호화 CPK에서 베이크 → `ux0/rePatch` + `ux0/reAddcont` 폴더 생성 → Vita의 `ux0:/`에 복사.
- CLI에도 `--vita3k <Vita3K 폴더>` 옵션을 추가했습니다(기존 `--ninpri/--ninpripatch`도 그대로 사용 가능 —
  MaiDumpTool 등으로 뽑은 *복호화* CPK 직접 지정용).
- 암호화/손상된 CPK를 넣으면 베이크 전에 즉시 친절한 메시지로 알려줍니다.

## 이슈 #17 — 튜토리얼 "멋지다 !"의 느낌표가 한자로 보이던 문제 (HD 텍스처팩 사용자)

- 원인: HD 폰트 텍스처(`6706A53E…`)의 ASCII 영역이 갱신되지 않아 `!`·숫자 자리에 원본 한자가 남아
  있었습니다(HD 텍스처팩을 쓰는 분에게만 발생).
- HD 폰트를 다시 생성해 `!`·숫자·문장부호가 정상 표시되도록 고쳤습니다. (HD 팩을 안 쓰는 분은 원래 정상)

## 이슈 #18 — 텍스처팩에 폰트 PNG가 빠진 것처럼 보이던 문제

- 실제로는 `5F01AD86…` 등 폰트 텍스처가 패치에 모두 포함돼 있습니다(설치 시 88개 전부 적용).
- 통합 GUI 번들에서 폰트 폴더가 눈에 잘 안 띄어 생긴 오해라, 번들에 `textures/kr/font/`도 보이도록 동봉했습니다.

## 참고

- 번역 내용 자체는 v1.4.1과 동일합니다.
- 원본 게임 데이터는 포함하지 않습니다 — 본인 게임(Vita3K 설치본)으로 패치를 직접 만듭니다.
- 실기 표시는 아직 베타입니다. 문제가 있으면 어떤 화면인지와 함께 제보해 주세요.
