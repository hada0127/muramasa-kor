# 무라마사 리버스 한글패치 v1.0.1

v1.0.0의 **폰트 외곽선(테두리) 문제**를 바로잡은 패치입니다.

## 🔧 이번에 고친 점

**폰트 롤백 문제 해결 — 글자 외곽선을 제자리로**
v1.0.0에서 글자에 검은 외곽선(테두리)을 다시 넣었는데, 이 외곽선이 들어가야 할 본문·대사 글씨뿐 아니라 **식당·찻집·상인 메뉴 글씨(그리운 경찰체)에까지 잘못 적용**되어 있었습니다. 메뉴 글씨는 원래 외곽선이 없어야 하는데 테두리가 생겨 어색했어요.

- **메뉴 글씨(식당·찻집·상인 등)**: 외곽선을 없앴습니다. 원래 디자인대로 깔끔하게 보입니다.
- **본문·대사 글씨(리디바탕체)**: 외곽선은 유지하되, **반투명이던 테두리를 진한 검정(불투명)으로** 바꿔 글자가 배경 위에서 더 또렷하게 읽힙니다.

## 설치 방법
이전 버전과 동일합니다. 동봉된 패처(Windows/macOS/Linux)를 실행하면 원본 CPK에 패치가 적용되고, 폰트·텍스처 파일이 Vita3K에 설치됩니다. 자세한 방법은 패처 안내와 README를 참고하세요.
