# 무라마사 리버스 한글패치 v1.2.1

**✕ 버튼 추가팩**에 빠져 있던 텍스처 하나를 더 채운 업데이트입니다. (이슈 #15)

## 🔧 이번에 고친 점

**✕ 버튼 추가팩에 메인 메뉴 화면(DF66CADD)이 빠져 있던 문제** (이슈 #15)
- v1.2.0의 ✕ 추가팩은 인게임 선택 아이콘과 시작 화면만 ✕로 바꿔, **메인 메뉴(저장/불러오기 등) 화면의 선택 ○ 표시는 그대로 ○로 남아 있었습니다.**
- 이번에 그 화면(우측 "아이템" 옆, 좌하단 "설정" 옆)의 ○ 2곳도 **✕로 바뀌도록** 추가했습니다. 시작 화면 표기도 다듬었습니다.
- 즉, ✕ 추가팩을 쓰면 이제 선택/확인 ○가 더 일관되게 ✕로 보입니다.

> ✕ 추가팩만 바뀌었고, **기본(○) 패치는 그대로**입니다. ○로 잘 쓰고 계신 분은 받지 않으셔도 됩니다.

### ⚠️ ✕ 추가팩 쓰실 때 (변함없음)
게임이 버튼 모양을 직접 그리기 때문에, 이 팩은 **화면 표시만** ✕로 바꿉니다.
실제로 ✕가 "확인"이 되게 하려면 Vita3K 설정에서 **Enter Button Assignment = Cross** 로도 바꿔주세요.

## 받는 법
- **기본 패치만 쓰는 분**: 바뀐 내용 없습니다. 그대로 두셔도 됩니다.

  - ○로 되돌리기: `python3 apply_xbutton.py --restore`
